# 連理の墓 LP（日蓮宗 長晶山 玉泉院）

期限付き二霊墓「連理の墓」のランディングページです。
HTML と CSS だけでできた静的サイトなので、ビルドは要りません。`index.html` をブラウザで開けば表示できます。

## ファイル構成

```
index.html        ページ本体（1ページ完結）
css/style.css     デザイン（色・文字・レイアウト、PC／タブレット／スマホ対応）
images/           写真・寺紋・地図
```

## よく変える場所

| 変えたいもの | 場所 |
|---|---|
| メインカラー（朱色） | `css/style.css` 冒頭の `--accent` |
| フォント | `css/style.css` 冒頭の `--font`（正楷書体 → 無い環境では Klee One） |
| お問い合わせフォームのリンク | `index.html` 内の `docs.google.com/forms/...`（4か所） |
| 電話番号 | `index.html` 内の `tel:0336410573` と表示中の番号 |
| Google マップのリンク | `index.html` 内の `maps.app.goo.gl/...` |
| 料金・使用期間など | `index.html` の `#price` セクション |

## 補足

- お問い合わせは Google フォーム「連理の墓 お問い合わせフォーム」です（回答はフォームの「回答」タブで確認でき、メール通知もオンになっています）。
- 正楷書体（HG正楷書体-PRO）は、そのフォントが入っているパソコンでだけ表示されます。ほかの環境では Web フォントの Klee One で表示されます。
- 地図の画像はチラシから切り出したものです。Google マップの埋め込み（iframe）に差し替えることもできます。
